# Contributing to Renext Technologies Website

Thank you for your interest in contributing to the Renext Technologies and SpendItWisely platform repository!

## Code of Conduct
We expect all contributors to maintain a respectful, professional, and collaborative environment.

## Development Workflow

1. **Fork or Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/renext-technologies.git
   cd renext-technologies
   ```

2. **Branching**:
   Create a descriptive branch for your changes:
   ```bash
   git checkout -b feature/interactive-enhancement
   ```

3. **Code Style Guidelines**:
   - Write semantic, accessible HTML5.
   - Keep styles clean, modern, and performant (using CSS variables).
   - Ensure all interactive features (calculators, simulators, canvas) run natively without third-party bloated libraries where possible.
   - Test across mobile, tablet, and desktop viewports.

4. **Submitting Changes**:
   - Push your branch to GitHub.
   - Open a clear Pull Request explaining your changes and motivation.
